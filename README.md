# 🚀 Blog App

A full-stack **MERN Blog Application** where users can create posts, like posts, and interact through comments.

---

## ✨ Features

- 🔐 User Authentication
- 📝 Create Posts
- ❤️ Like / Unlike Posts
- 💬 Add Comments
- ✏️ Edit Comments
- 🗑️ Delete Comments
- 📄 Single Post View
- 🚦 Protected Routes
- 🔔 Toast Notifications
- ⚡ Responsive UI

---

## 🛠️ Tech Stack

### 🎨 Frontend

- ⚛️ React
- ⚡ Vite
- 🛣️ React Router DOM
- 🌐 Axios
- 🔔 React Hot Toast
- 🎨 Remix Icons

### ⚙️ Backend

- 🟢 Node.js
- 🚂 Express.js
- 🍃 MongoDB
- 🧩 Mongoose
- 🔐 JWT Authentication
